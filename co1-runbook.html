INSTRUCTOR HANDOUT · 90 MINUTES · PROJECT + LAPTOPS

CO1 teach-runbook: theory, then immediately the practice

Business Intelligence & Data Visualization (26MB5210E) · one 90-minute session · you project the slides, students open the links on their own laptops.

Teach — the slides you project (open co1-theory.html, arrow keys turn pages) Try — the link students open now; every answer auto-saves in their browser Check — one question you can ask in the room, no marks needed
BlockTeach · slidesTry · student linkCheck
1 · 15 min What BI is · S3–S4. Data → information → insight → action; value only when a decision changes. Point at the “Now try it” chip at the bottom of S4. co1-dashboard.html#dikw
Sort the five statements, then answer one “what did I learn”.
 Ask one student to classify a statement from their own week (a class mark, a bus log) — where is the information, where the insight?
2 · 15 min How value moves · S5–S6. The value chain and the lifecycle; where chains break. Chip on S5. co1-dashboard.html#value-chain then co1-dashboard.html#bakery
Find the broken stage, then set the bakery quantities and compare your profit to the 30-a-day gut feeling.
 Two cold calls: “which stage did you break” and “what did you bake on a Saturday, and why?”
3 · 20 min Four kinds of questions · S9–S10. Descriptive, diagnostic, predictive, prescriptive — the maturity staircase. Read The case tab of the labs page together for 2 minutes. Chip on S10. co1-labs.html#case then co1-labs.html#lab-1-1
Classify all twelve mess questions; answer one of each type; press “New sample” once to see the numbers move.
 Score pill hits 12/12 — ask who acts on the prescriptive answer (the supervisor rosters the 12:45 shift).
4 · 20 min Dashboards fit the audience; data gates the model · S11, S12, S18. Four dashboard types and the quality gate. Chip on S11, S12 and S18. co1-dashboard.html#dashboards then co1-labs.html#lab-1-2
Match the dashboard; interview the five stakeholders, run the three data checks, rank with MoSCoW and plan the 20-point release — then compare with “best plan”.
 “Which MoSCoW call do you disagree with, and which data check forced it?”
5 · 15 min Frame the decision · S15–S16. Work backwards: decision → question → metric → data; SMART-D. Chip on S16. co1-dashboard.html#framing
Write the decision behind “a dashboard on sales”, one business question, and one complete KPI.
 One KPI read aloud — the room flags whether it has formula, unit, grain, source and owner.
6 · 5 min Wrap · S20. The “I can now” checklist; homework: one activity from each dashboard part. co1-dashboard.html#submission
Enter name + student ID, complete any missing write-ups, save the PDF (and Word if asked).
 Submissions tab shows “All parts are complete” — no empty or one-word write-ups.

How it works: everything runs in the browser — no installs, no accounts. Answers save automatically in each student’s own browser (per station); the Submission tabs build a named PDF/Word report from what they did. No laptops? Teach each block projected; students hand-write the write-up sentences, you collect on paper — the check questions work unchanged.
